# Security

Authentication and authorization are intentionally outside this exemplar. The application defaults
to a loopback listener. Anyone who can reach it can upload and retrieve artifacts; access control is
required before exposing it beyond a trusted development environment.

Do not put credentials, uploaded content, or exploit details in public issues. Report vulnerabilities
through this repository's GitHub **Security → Advisories → Report a vulnerability** when private
vulnerability reporting has been enabled. If it is unavailable, contact a repository maintainer
privately through their published GitHub contact details.

Only the latest repository revision and most recent stable release are maintained. Review dependency
and CodeQL alerts promptly. There is no promised incident response SLA for this reference project.
